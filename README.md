# Deadlock Hub

A fan-made concept of a community hub for Valve's hero shooter Deadlock: hero builds with win rates, a leaderboard, news, a farm-route timer, a patch timeline and a forum. Plain HTML, CSS and JavaScript in one file, no build step.

## What is on the page
- A night city under the title; the team switch (Amber Hand or Sapphire Flame) changes the photograph and every accent on the page
- Six section tiles, each in its own colour
- Builds: search and sort the heroes, three builds each with items by category
- Players: a leaderboard with a region filter, the top three marked
- News, a farm route by game minute, a patch timeline and a forum where you can post and vote

## Run it
```bash
npx serve .
```

Not affiliated with Valve. Statistics, players and forum threads are sample data. Photographs from Wikimedia Commons, listed in `credits.html`.
